# Ohmatt AI Systems Ltd

Static company profile for `ohmatt.com`. The standalone site links to the Ohmatt AI product at `ai.ohmatt.com` and is intentionally independent of the authenticated product frontend.

## Deploy

Connect this repository to a Vercel project with the project root at the repository root and attach `ohmatt.com` and `www.ohmatt.com` to that project. Keep `ai.ohmatt.com` attached to the Ohmatt AI frontend project. Configure the DNS records Vercel shows for this project; do not reuse guessed records.

The site is static and has no build step. `index.html`, `styles.css`, and the public logo asset are served from the repository root.

## Claims and launch checks

- Company identity and CAC registration number are shown from the incorporation certificate.
- NDPC details identify the certificate's prior company name and state that a name update was requested; update this wording only after NDPC confirms the change.
- Do not present NDPC registration as product endorsement or as blanket proof of compliance.
- Publish the approved privacy notice, terms, and DPO contact before inviting customers to connect financial accounts.
